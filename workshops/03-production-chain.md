# 实战三：从选题到发布的完整制作链

**输入**：真实观众问题、自己可操作的素材、至少 2–3 个核验来源、可公开演示环境。没有证据时先停止脚本生成。

| 环节 | 可用工具（非必须） | 人必须完成的动作 | 交付物 |
| --- | --- | --- | --- |
| 发现需求 | YouTube 搜索/评论、GitHub Issues | 留来源链接、筛选真实问题 | TOPICS CSV |
| 选题评分 | 本站评分器、`scripts/score_topics.py` | 人打分并解释 | VIDEO_BRIEF |
| 事实查证 | 官方文档、GitHub 版本记录 | 逐条核对价格、功能、案例、日期 | FACT_CHECK |
| 脚本 | ChatGPT、其他文本助手 | 人验证并改成自己能录的步骤 | SCRIPT_BEATS |
| 录屏 | macOS 截屏、OBS | 亲自操作真实软件并保护隐私 | MOV/MP4 原片 |
| 旁白 | 自己配音、经许可的语音工具 | 校对内容、确认版权与披露 | WAV/MP3 |
| 剪辑 | CapCut/剪映、DaVinci、Remotion | 清掉等待、放大按钮、加字幕 | 6–10 分钟长视频 |
| Shorts | 剪辑软件 | 改成 9:16 独立叙事，非机械横转竖 | 2–3 条可读竖屏 |
| 封面 | FreeCover、Figma/Canva | 用真实画面做 3 套差异化设计 | 1280×720 图片 |
| 发布 | YouTube Studio | 人工检查字幕/素材/AI use/链接 | 真实视频链接 |
| 复盘 | YouTube Analytics | 24h / 72h / 7d 记录数据 | RETRO_7D |

**成本优先级**：第 1 月优先用现有设备、免费工具和原创录屏。没有观众数据时不采购批量生成服务；若实际留存差，优先修画面和脚本，而非购买更贵模型。

**五步法**：质疑每一步是否有观众价值 → 删除不必要特效/平台 → 优化操作清晰度 → 缩短制作周期 → 最后自动化重复性检查。
