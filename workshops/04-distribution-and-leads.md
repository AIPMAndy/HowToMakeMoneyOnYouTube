# 实战四：一条 YouTube 视频，如何拆成多平台内容与线索

示例长视频：“免费的开源工具怎样遮住截图里的个人信息？”

- **YouTube 8 分钟教程**：完整录屏，讲清输入→操作→错误→最终结果，视频说明附 Github 原项目和教程。
- **Short 1（15–25 秒）**：展示遮挡前后对比，强结果钩子。
- **Short 2（25–40 秒）**：只演示一段最难的操作，评论区引导观众看完整教程。
- **Threads**：用已经证明适合你账号的“说个冷知识”句式，具体交付一条可做操作，不要机械重复长视频广告。
- **X 长文**：图文讲解 5 步，附 GitHub 截图和源码链接。
- **GitHub**：把可复制步骤沉淀成章节独立 URL，增加后续搜索可发现性。

### 追踪归因

不同平台链接可用不同参数，例如：

```text
https://metaver.vip/?utm_source=youtube&utm_medium=video&utm_campaign=freeredact
https://metaver.vip/?utm_source=threads&utm_medium=social&utm_campaign=freeredact
```

UTM 是标注流量来源的约定，并不是自动统计服务；要在你实际使用的网站分析工具中才能看到访问。若使用 GitHub 开源库链接，至少分别记录各平台发布链接与有效反馈，不能仅凭浏览数估算转化。

### 商业闭环判断

普通工具观众优先获得免费工具。有人提出实际职业/副业规划问题，才自然告知当前 400 元咨询或 4500 元专项陪跑；企业提出项目合作需要时对接企业咨询。每期视频只给一个合适的行动入口。

**验收**：同一主题的 1 长+2 短+1 Threads+1 X+1 GitHub 指南；至少一次真实访客或问题反馈的人工核对；不把关注/点赞自动等同成交。
