# 演进计划

## 已纳入 V2 源码

36 章指南、36 个 Andy 视频选题、90 天带证据任务、12 周起号策略、FreePhoto 全镜头脚本、CSV 视频诊断、浏览器情景测算、发布审核门禁、19 条公开来源和 37 URL 静态站点。

## V3 应基于真实数据决定，而不是继续堆功能

1. 邀请 **3 位从未做过视频的新手** 现场按工作坊录出第一条视频，记录卡点与完成率；现在尚未做。
2. 用户手动导入 YouTube Studio 实际导出 CSV，适配不同语言列名并对齐时间窗口。当前只接受规范化模板。
3. 完成第一批 4 条长视频和 8 条 Shorts 后再设“保留/砍掉/加码”门槛。
4. 有真实转化台账后验证内容主题与有效询盘之间的关系，不以跨平台浏览量代替。
5. 正式仓库发布后检查 GitHub Actions、Pages、移动端加载、真实外链与 Web Vitals。
6. 在 2027-02-01 前复核 YouTube 新门槛生效与页面准确性。

**明确暂不做**：全自动批量上传、未经确认的 AI 新闻采集、虚构流量或收入截图、请求用户账号密码的第三方插件。
