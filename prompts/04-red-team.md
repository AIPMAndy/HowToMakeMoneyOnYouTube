# Prompt 4：Builder / Red Team / Judge 三轮对抗

请对我提供的单集视频脚本、素材来源清单、封面与商业入口开展三轮审查：

**Builder**：从用户第一次打开软件开始，找出所有按钮缺失、输入前置条件不清、素材无法获得、输出无验收标准的问题。

**Red Team**：扮演 YouTube 版权与变现审核、容易流失的新观众、无预算的新手三种角色。逐项寻找原创性不足、误导性标题、收入数据无证据、AI 写实内容未披露、授权缺口、隐私泄露、广告与教学混淆的问题。

**Judge**：给每条发现标记 `PASS / FIX / BLOCK`，引用实际视频时间戳或文件行号，按观众影响、合规风险、商业损失排序。只有检查证据充分才能 PASS，未实际执行的测试写“未验证”。输出可逐项修复的任务列表和复验方法。
