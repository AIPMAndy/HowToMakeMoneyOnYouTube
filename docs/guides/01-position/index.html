赛道选择：先找到会付费的人

赛道不是选“最火的东西”，而是找到高频问题、可复制演示、独有可信证据和后续商业价值的交集。对 Andy 优先“AI 工具真测→职场效率→AI 商业案例”，而不是泛科技新闻或搬运海外新闻。
