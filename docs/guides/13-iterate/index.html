实验设计：一次只验证一个关键假设

同样题目下变换封面、开头或时长，都会影响结果；小样本很容易被偶然波动误导。把视频当产品做，每周只挑一个最大瓶颈修复，保留版本和截图。 每一步都要留下可复查的实际结果，不能只做文字总结。
