制作 · GUIDE 09

剪辑：只留推动理解的画面

初期追求观众看懂，不追求电影级复杂动画。主要剪掉等待、重复点击、空白停顿；必要处放大操作区、加简短字幕、对比结果。复杂动效可以用 Andy Video Skill/Remotion 等工具辅助，但不是第一周必须品。

跟着做：逐步完成

这些勾选仅在当前页面有效；完整进度请在主页勾选并导出备份。

完整示例：本章怎样落地

删除等待加载和重复点击，但保留用户能跟上的参数与反馈。

最容易失败的地方

字幕漂亮，但观众看不清按钮。

验收门槛

验收：能够展示「一条完整 MP4 + 3 条 Shorts 切片 + 校验清单」的实际文件或可访问链接，并逐项对照步骤；没有证据则未完成。

本章交付物

一条完整 MP4 + 3 条 Shorts 切片 + 校验清单

关键判断

剪辑速度不能高到观众看不清点击位置。
