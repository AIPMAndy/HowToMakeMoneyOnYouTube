# Faceless YouTube Creator Playbook · By AI Chief Andy

A free, practical, evidence-aware Chinese-language open-source guide to creating **original faceless YouTube content**, growing through real feedback, and exploring sustainable monetization.

**Included**: 36 task-focused guides, a 90-day checklist, 36 starter ideas tailored to an AI tools educator, four real channel case studies plus one proposed Andy experiment, a local topic scorer, a local progress tracker, a browser funnel economics calculator, a creator analytics clinic, a CSV analyzer and an evidence-based release gate, 19 time-stamped primary source links and contributor-friendly templates.

The website is static: no account, no analytics tracker, no third-party JavaScript. The project does **not** generate spam videos or upload without a human review.

```sh
python3 scripts/build.py
python3 -m http.server 8000 -d docs
python3 -m unittest discover -s tests -v
```

**Publishing**: create a public repository named `HowToMakeMoneyOnYouTube` and upload the source. Then enable GitHub Pages (GitHub Actions). The intended Pages URL is not claimed to be live before deployment.

**Revenue claims**: earnings shown in creator-owned sources are marked self-reported; we do not extrapolate them into guaranteed revenue. Official YPP thresholds should be verified in YouTube Studio; the 2027-02-01 eligibility updates are documented with their effective date.
